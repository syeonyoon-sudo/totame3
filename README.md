# 또타미 (TOTA:ME) — 이용자 맞춤형 스마트 지하철 모빌리티 서비스

> **Your Personal Subway Companion**
> 출발 → 탑승 → 환승 → 역사 내부 이동 → 하차 → 목적지 → 이동 기록까지

React + TypeScript + Vite + Tailwind CSS 모바일 웹앱입니다. 스마트폰에서는 전체 화면 앱처럼, 데스크톱에서는 스마트폰 프레임 시연 모드로 동작합니다.

---

## 1. 메뉴 구조

| 하단 탭 | 역할 | 주요 기능 |
|---|---|---|
| **홈** | 출발 전 대시보드 | 출발·도착 검색, 스마트 출발 도우미, 열차 운행 정보, 주요 역 혼잡도, 최근·즐겨찾기 경로, 주변 역, 외국인 모드, 광고 |
| **경로** | 경로 검색·비교 | 10가지 이동 조건 + 우선순위, 경로별 시간·환승·도보·혼잡도·지연·도착시각·출구·추천 이유, 출발역까지 스마트 출발, 즐겨찾기 |
| **지금 어디?** | 이동 중 내비게이션 | 미니 지도, 현재 노선·역·다음 역, 진행률, 탑승 전 카운트다운, 지연 반영 도착시간, 혼잡 칸 추천, 환승 예정역, 스마트 환승, 장애 대응·대체 경로, 역사 내부 안내, 도착 화면(출구·외부 지도) |
| **이동 리포트** | 이동 기록 분석 | 오늘·주간·월간 통계, 지연 추가 시간, 그래프, 인사이트, 기록 삭제 (요일·시간대 상세 패턴은 프리미엄) |
| **마이페이지** | 계정·설정 | 회원정보, 프리미엄·구독 관리, 언어·Foreign Mode, 보행속도, 이동 성향, 출발지·즐겨찾기, 알림, 음성, 접근성, 개인정보·위치정보 |

탭 위에 열리는 화면: 스마트 출발 도우미 · 혼잡도 · 역사 내부 안내 · 외국인 모드 · 프리미엄

## 2. 사용자 흐름 (시연 순서)

1. **홈** 스마트 출발 카드 → 출발지(학교·이대역 450m 예시) 기준 "지금 출발하면 뛰어야 할까?"
2. 도착역 검색 → **경로** 비교 (혼잡도·지연·출구 표시, 출발역까지 출발 안내)
3. **이 경로로 안내 시작** → **지금 어디?** (탑승 전 카운트다운 → 진행률·남은 정거장)
4. 혼잡 칸 추천 → 혼잡도 화면(칸별 객실 UI)
5. **스마트 환승** 카운트다운 (보행속도에 따라 "여유 있어요 / 조금 서둘러 볼까요? / 환승 시간이 촉박해요 / 무리하지 마세요")
6. **장애 대응 › 열차 지연** → 푸시 알림, 도착시간 재계산, 기존 조건을 유지한 대체 경로
7. 하차 사전 알림 → 도착 → **출구 선택 → 카카오맵/네이버지도**, 이대역은 **역사 내부 길 안내**
8. **이동 리포트**에 자동 기록 (지연 추가 시간 포함)

## 3. 구현 현황 — 세 가지로 구분

### ① 실제 데이터 연동까지 완료
- **역·노선 536개 역** (1~9호선, 공항철도, 경의중앙, 수인분당, 신분당, 우이신설, 신림, 김포골드) — 좌표·4개 언어 역명·노선 연결 (OpenStreetMap)
- **요금 안내** — 서울시 교통요금(2025-06-28 시행): 교통카드 일반 1,550원 / 1회권 1,650원 / 청소년 900원 / 어린이 550원 / 조조 1,240원, 거리비례 운임 계산
- **기후동행카드 단기권** — 1일 5,000원 · 2일 8,000원 · 3일 10,000원 · 5일 15,000원 · 7일 20,000원 (서울시 안내)
- 다익스트라 기반 맞춤 경로 탐색(10가지 조건), 4개 언어 UI·역명, 위치 권한·동의, 알림(인앱·알림음·진동·음성·시스템 알림), 이동 기록 저장·삭제

### ② 화면·동작은 구현됐고 API 키 / 데이터 확보가 필요
| 기능 | 현재 상태 | 필요한 것 |
|---|---|---|
| 실시간 도착정보 | `api/arrival.ts` 완성 | `SEOUL_SUBWAY_API_KEY` |
| 열차 지연 계산 | 시뮬레이션 지연은 전체 기능과 연동. 실시간 정보가 없으면 "실시간 운행정보를 확인할 수 없어요"로 표시 (정상 운행이라고 단정하지 않음) | 실시간 API + 공식 시간표 데이터 |
| 역·칸별 혼잡도 | 시간대·역 특성 기반 **예상값** (화면에 "예상" 표시, % 미표시) | SK open API 등 실시간 혼잡도 (유료·일부 노선) |
| 역사 내부 내비게이션 | 길찾기 엔진·층별 지도·6가지 이동 방식·QR 위치 인식 완성. **이대역은 시연용 개략 도면** | 실제 역사 도면·시설 좌표 (서울교통공사) |
| 출구·첫차/막차·역 코드 | 이대역은 도면 출구, 그 외 예시 / 막차 예상 | 공공데이터포털 출구·시간표 |
| 카메라 번역 | 촬영·업로드·서버 함수(`api/translate.ts`) 완성 + 오프라인 표지판 사전 | `GOOGLE_CLOUD_API_KEY` (Vision + Translation) |
| 프리미엄 결제 | 토스페이먼츠 결제창 → 서버 승인(`api/payments/confirm.ts`) 후에만 구독 활성화. 키가 없으면 결제 버튼 비활성 | `VITE_TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY` (테스트 키로 테스트 결제) / 정기결제는 빌링 계약 |
| 회원가입·로그인 | Supabase Auth REST 연동 코드 완성 | `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` + `supabase/schema.sql` |
| 광고 | 하우스 광고(가상 업체) 5개 영역, 프리미엄 시 제거, 이동 안내 화면 미삽입 | Google AdSense 승인 |

### ③ 네이티브 앱 또는 별도 하드웨어 필요
- 화면이 꺼진 상태의 백그라운드 위치 추적·알림
- Wi-Fi·BLE 비콘 실내 측위 (웹은 QR·직접 선택으로 대체)
- 정확한 이어폰 연결 감지, Apple Watch·Galaxy Watch 전용 화면·햅틱, iPhone 진동

> 시연 편의를 위해 마이페이지 › 프리미엄에 **"프리미엄 기능 미리보기 (결제 아님)"** 토글이 있습니다. 결제나 구독 상태로 기록되지 않습니다.

## 5. 환경변수 (모두 선택 — 없어도 앱은 동작)

| 변수 | 위치 | 용도 |
|---|---|---|
| `SEOUL_SUBWAY_API_KEY` | 서버 | 서울시 실시간 도착정보 |
| `GOOGLE_CLOUD_API_KEY` | 서버 | 카메라 번역 (OCR + 번역) |
| `TOSS_SECRET_KEY` | 서버 | 결제 승인 (`test_sk_…` = 테스트) |
| `VITE_TOSS_CLIENT_KEY` | 클라이언트 | 결제창 (`test_ck_…` = 테스트) |
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` | 클라이언트 | 회원·이동 기록 DB |
| `VITE_ADSENSE_CLIENT`, `VITE_ADSENSE_SLOT_*` | 클라이언트 | 애드센스 |

서버 변수는 Vercel 환경변수에만 넣으세요 (클라이언트 번들에 포함되지 않음). `.env.example` 참고.

## 6. GitHub 업로드 · Vercel 배포

```bash
git add .
git commit -m "또타미 v3"
git push
```

GitHub 웹에서 올릴 때는 **압축을 푼 폴더 안의 항목 전체**(`src`, `public`, `api`, `scripts`, `supabase` 포함)를 한 번에 드래그하세요. Vercel은 Framework **Vite**, Output `dist`로 자동 인식되며 `/api/*` 서버리스 함수도 함께 배포됩니다. `/route`, `/move`, `/report`, `/my`, `/pay/success` 새로고침 시 404가 나지 않습니다.

## 7. 프로젝트 구조

```
├─ api/                       # Vercel 서버리스 (실시간 도착, 번역, 결제 승인)
├─ supabase/schema.sql        # trips 테이블 (+ delay_min)
├─ scripts/                   # 역 데이터 생성 (OSM 원본)
├─ public/                    # 파비콘, 매니페스트, 서비스 워커
└─ src/
   ├─ data/      network.ts(노선·역) · indoor.ts(실내 도면) · foreign.ts(요금·관광·긴급)
   ├─ lib/       routing(경로) · boarding(스마트 출발·환승 공통 계산) · indoor(실내 길찾기)
   │             congestion(혼잡 예상) · notify(알림) · geo(위치)
   ├─ services/  delay(운행 상태) · trips(기록) · auth(회원) · premium(결제) · maps · ads · realtime
   ├─ i18n/      messages.ts + messages-v3.ts (한/영/중/일)
   ├─ state/     store.tsx
   ├─ components/
   └─ screens/   Home · Route · Move(지금 어디?) · ReportScreen · My · SmartDeparture
                 CongestionScreen · IndoorNav · ForeignMode · PremiumScreen
```
